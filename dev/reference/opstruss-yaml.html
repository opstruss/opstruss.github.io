opstruss.yaml ​

An OpsTruss project, or a component when used through uses:.

Keys that start with x- are left for your own use.

KeyTypeDescription
namestringThe name of the project: lowercase letters, digits, - and _, starting with a letter.
descriptionstringWhat the project is for.
opstrussstringThe oldest OpsTruss version that reads this file, as MAJOR.MINOR.
includelist of stringFiles merged into the project, as globs relative to this file.
usesmap of string or UsesPlugins, components, and catalogs that the project uses, by the name it calls them.
inputsmap of InputInputs of the project, which stacks, --input, or a prompt give.
localsobjectNamed values computed from inputs and other locals, read as locals.<name>.
outputsmap of string or Project outputsOutputs of the project, which opstruss outputs prints and a project that uses it as a component reads.
stacksmap of StackThe stacks of the project: copies of its units, each with its inputs and its own state.
backendlocal or BackendWhere the state of the stacks is kept: local, in .opstruss/state/, the only backend of this version.
secretsmap of SecretSecrets of the project, read as secrets.<name> and hidden in what OpsTruss writes.
encryption_keyslist of string or Encryption keysWhat opens the data key of each stack, which encrypts sensitive values in the state.
runtimeRuntimeSettings of the daemon of each stack.
mcpfalse or MCPReserved for opstruss mcp, which a later version brings; not supported in this version, which refuses it.
unitsmap of UnitThe units of the project, which up brings up and destroy takes away.
tasksmap of TaskThe tasks of the project, each also a command of opstruss.
movedlist of MovedUnits that changed address, so that their records move rather than being destroyed.
removedlist of RemovedUnits gone from the files, and whether destroy takes away what they made or their records are forgotten.

Include file ​

A file merged into a project through include:.

KeyTypeDescription
usesmap of string or UsesWhat a project uses, by name: a source, or an object with source and what every use of it gets.
inputsmap of InputInputs by name.
localsobjectNamed values, each an expression, read as locals.<name>.
secretsmap of SecretSecrets by name.
unitsmap of UnitUnits by name.
tasksmap of TaskTasks by name.
movedlist of MovedAddresses that changed, from the old to the new.
removedlist of RemovedUnits gone from the files.

Env ​

Variables set for programs: a value, or {file: <value>} to write the value to a file and set the variable to its path.

KeyTypeDescription
file (required)stringThe value, written to a file whose path the variable gets.

Stdin ​

What a program reads on its standard input.

KeyTypeDescription
value (required)anyThe value: text, or data that format writes.
formatone of text, json, yaml, lines, dotenvHow the value is written; text by default.

Paths ​

Paths and globs relative to this file, read as written, without shell variables; {exclude: <glob>} leaves files out of those before it.

KeyTypeDescription
exclude (required)stringA glob of files to leave out of the patterns before it.

Retry ​

Running a program again when it fails.

KeyTypeDescription
attemptsintegerHow many times the program runs at most, the first one included.
delaystringThe wait before the second attempt.
backoffnumberWhat each wait is multiplied by for the next one.
untilstring or booleanA condition on the outputs that ends the attempts when true.

Stop ​

How a program is stopped, at cancel, timeout, or the end of a service.

KeyTypeDescription
signalstringThe signal that asks the program to stop; SIGINT by default, SIGTERM for a service.
gracestringHow long the program has after the signal before it is killed; 1m by default, 10s for a service.
runstring or list of stringA program that stops a service, instead of the signal.

An input: its type, its default, and the checks of its value.

KeyTypeDescription

descriptionstringWhat the input is for, which help shows.
requiredbooleanWhether the input must be given.

KeyTypeDescription

fromone of stdout, stderr, file, outputWhere the value comes from: stdout, stderr, the file at path, or output, the lines name=value written to $OPSTRUSS_OUTPUT; output by default.

Uses ​

What a project uses, by name: a source, or an object with source and what every use of it gets.

KeyTypeDescription
source (required)stringWhere it comes from: a path, github.com/<owner>/<repo>[/<path>]@<ref>, <catalog>.<name>, or opstruss.<task> for a built-in task.
withobjectInputs given to every use of it, under those of the use.
envmap of string or EnvVariables set for its programs, under those of the use.
passlist of stringVariables of the environment that its programs get when it asks for them, by name or pattern; not * alone, since the units that use it keep their values in their digest.

KeyTypeDescription

withobjectInputs of the backend plugin.

Secret ​

One source: sops, env, run, or a call of a plugin task whose output is value.

KeyTypeDescription
sopsstringA file encrypted with sops, relative to this file; a dotenv, JSON, or YAML file is a map.
fieldstringOne field of the decrypted file, as a dotted path.
envstring or map of string or EnvThe variable of the environment that holds the secret, or, with run:, variables for its program.
runstring or list of stringA program whose standard output is the secret, such as op read.
passlist of stringVariables of the environment that the program of run: gets.
dirstringThe directory the program of run: starts in, relative to this file.
shellone of sh, bash, python, node, pwshThe shell that runs run: when it is a script.

Any other key is a call of a task by that name, with its inputs as the value.

Unit ​

A unit: something that up brings up and destroy takes away, with exactly one of run, service, or uses.

KeyTypeDescription
descriptionstringWhat the unit is.
runstring or list of stringThe program that brings the unit up.
servicestring or list of stringA program that keeps running, which the daemon of the stack supervises.
usesstringThe plugin, task, or component that the unit uses.
withobjectInputs of what the unit uses.
tasksmap of TaskTasks of the unit, run as opstruss <task> [unit]...
requiresstring or list of stringPrograms that must be in PATH before the unit runs.
shellone of sh, bash, python, node, pwshThe shell that runs a script; sh by default.
dirstringThe directory that the programs start in, relative to this file.
envmap of string or EnvVariables set for the programs of the unit.
passlist of stringVariables of the environment that the programs of the unit get; not * alone, since the unit keeps their values in its digest and destroy context.
stdinStdinWhat the program reads on its standard input.
sourceslist of string or PathsFiles whose content is part of the definition, so a change to one runs the unit again.
generateslist of stringFiles that the unit makes, relative to this file and read as written; a missing one runs the unit again.
revisionstringA value whose change runs the unit again.
outputsmap of OutputOutputs of the program, which other units read as units.<name>.outputs.<output>.
destroystring or list of stringThe program that takes the unit away, which its record keeps.
restartone of no, on-failure, alwaysWhen the daemon starts the service again after it exits: no, on-failure, or always; on-failure by default.
stopStopHow the program is stopped.
readyUnit › readyWhen the service counts as started: a URL, a port, or a program; up waits for it.
needslist of stringUnits that come before this one, besides those its expressions read.
ifstring or booleanA condition that decides whether the unit is in the stack; one that leaves it is destroyed.
for_eacharray or object or stringA list or a map: one instance of the unit per item, read as each.key and each.value.
approvalone of ask, autoask to wait for approval of changes to this unit, auto to apply them without asking.
timeoutstringHow long a program of the unit may run.
protectbooleanRefuse to destroy the unit.
retryRetryRunning the program again when it fails.

Triggers ​

What runs a task from the daemon of the stack.

KeyTypeDescription
schedulestring or Schedule or list of string or ScheduleCron schedules, in the time zone of the machine unless timezone names another.
everystring or list of stringIntervals, such as 5m, from when the daemon starts.
webhookWebhook or list of WebhookHTTP requests to the daemon that run the task.
watchWatch or list of WatchEvents from files, the output of a service, or a program that writes a line per event.
afterAfter or list of AfterRuns of other tasks or commands that this task follows.

Schedule ​

A cron schedule, as a string or with its options.

KeyTypeDescription
cron (required)stringA cron expression of five fields, or a shorthand such as @daily.
timezonestringAn IANA time zone, such as Asia/Jakarta; the time zone of the machine by default.
persistentbooleanRun once what was missed while the daemon was not running or the machine slept.
ifstring or booleanA condition on the event that skips the run when false.
withobjectInputs of the task for runs of this trigger.

Webhook ​

An HTTP request to the daemon that runs the task, checked by its signature.

KeyTypeDescription

methodone of GET, POST, PUT, PATCH, DELETEThe HTTP method; POST by default.
secret (required)stringThe secret that signs the requests, as ${{ secrets.<name> }}.
signature (required)one of github, gitlab, slack, stripe, standard, bearer or Webhook › signatureHow a request is checked: the scheme of github, gitlab, slack, stripe, standard webhooks, or bearer, or a header of your own.
respondone of accepted, waitaccepted to answer 202 with the id of the run at once, or wait to answer with the outputs of the task.
ifstring or booleanA condition on the event that skips the run when false.
withobjectInputs of the task for runs of this trigger.

Webhook › signature ​

How a request is checked: the scheme of github, gitlab, slack, stripe, standard webhooks, or bearer, or a header of your own.

KeyTypeDescription

algorithmone of sha256, sha512The hash of the HMAC.
encodingone of hex, base64How the signature is written.
prefixstringText before the signature in the header, such as sha256=.
