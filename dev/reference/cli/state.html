opstruss state ​

Read and repair the state of a stack without touching its storage.

Global flags ​

FlagDescription
-C dirrun as if OpsTruss started in dir, like git -C; a -C after another is relative to it
--input stringArrayset a project input, as name=value
--jsonprint JSON
--lockedrequire existing dependency pins without changing opstruss.lock
--stack stringthe stack to use; defaults to the only one, or $OPSTRUSS_STACK

Commands ​

CommandDescription
opstruss state listList the records and kv keys of the stack
opstruss state pullPrint one record or key as stored
opstruss state pushReplace one record or key from stdin
opstruss state rmForget a record without destroying anything
